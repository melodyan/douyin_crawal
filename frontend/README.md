# 采集工作台前端

Vue 3 + Vite + TypeScript 单页界面，目前使用模拟任务数据，不连接 Python 采集程序。

## 启动

在 `frontend` 目录执行：

```powershell
npm install
npm run dev
```

## 页面

- **任务列表**：查看最近采集视频；可按采集时间、发布时间、视频名称/转写/作者模糊匹配，以及点赞、收藏、转发数量范围筛选。新建任务通过弹窗创建，支持单个短视频、合集、指定作者，并可多选视频采集与评论采集模块。转写操作位于每条视频的操作列。
- **采集配置**：分区编辑 `config.example.yaml` 中的配置项。除 MiMo API Key 外，配置保存在当前浏览器的 localStorage；API Key 仅保留在当前页面内存中。
- **临时配置**：创建任务时开启后，可选择覆盖评论上限、作者/合集作品上限和已完成任务重跑选项；其余配置沿用配置页面的默认值。

任务列表、进度和任务状态均为前端演示数据。连接后端前，保存配置也只会写入当前浏览器，不会修改项目中的 YAML 文件。
